# configs

Condition definitions (role x visibility x pressure), seeds, and the model registry (`models.yaml`: provider, model, effort, token limit). `spike.yaml` is the feasibility spike, `calibration.yaml` the exploratory pressure levels (`pressure_levels.yaml`), and `study1.yaml` Study 1 (SPEC v3): pressure level 4, five scenarios, and a fixed allocation (main design and speaker-free sensitivity runs). See SPEC.md.
